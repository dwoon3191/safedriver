# v1.0.4 변경사항

## 1. 배차표 508건 저장 시 statement timeout
원인: 기존 RPC가 각 행마다 driver 계정 생성을 시도하며 bcrypt 해시를 반복 생성하고 508행을 한 트랜잭션에서 순차 처리했습니다.

수정:
- 두 배차표의 동일 배차를 브라우저에서 우선 병합
- 100건 단위로 분할 RPC 저장
- DB에서 초기 비밀번호 1111의 해시를 import당 1회만 생성
- dispatch insert/update를 집합 처리
- 저장 완료 후 업로드 자료 운행일자로 자동 조회

기존 DB는 `sql/04_dispatch_import_timeout_fix.sql`을 1회 실행합니다.

## 2. TAGO 서비스키
창원시 기존 API가 아니라 공공데이터포털의 TAGO API 키를 사용합니다.
필요 API:
- 15098529 버스노선정보
- 15098533 버스위치정보

두 API 활용신청에서 같은 프로젝트/개인 서비스키를 선택하는 것을 권장합니다.
