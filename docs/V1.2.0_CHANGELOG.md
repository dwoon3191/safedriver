# v1.2.0 변경사항

## 목적 재정의
- 공단 리포트 Excel 업로드 중심 기능 제거
- CDT+BIS 기반 기사별 SafeDrive 내부 분석으로 전환
- 실제 운행차량 확정과 기사 피드백을 시스템 핵심으로 설정

## 배차/시간표
- 일일 배차 Excel 다중 업로드
- 기사 근무자료와 일일 노선·운행순위 자료 자동 병합
- 노선별 시간표 다중·버전 업로드
- 평일/토요일/일·공휴일 블록 자동 인식
- 공단순환 등 변형 시트를 위한 ‘순번’ 열 자동 탐색
- 방학/특별 시간표 유효기간 관리
- 공휴일·특수일 수동 지정

## BIS 실제차량
- 현재 운행 가능한 회차만 비교
- 출발 전 대체차량과 운행 중 차량교체 구분
- 동일 불일치 반복 확인
- 다중 불일치 시 출발시각과 정류소 진행순서 참고
- 실제차량 유효구간 저장
- BIS 전체 위치자료 미저장

## CDT 지연수집
- 파일 수집일이 아닌 원래 운행일 기준 매칭
- 며칠 뒤 수집된 파일도 배차·BIS 이력에 재연결
- pending/partial 자동 재시도
- 설정/처리상태 보존

## 기사 분석
- SafeDrive 자체 점수·수준
- 급출발/급가속/급감속/급정지/관리속도 후보
- 100km당 발생률과 대표 근거
- 관리자 기사별 조회
- 기사 모바일 확인 및 확인여부 관리

## 저장공간
- CDT 원본·1초 레코드 미업로드
- BIS 전체 위치 미업로드
- 파일 메타, 일일집계, 대표 이벤트만 저장
- 보존기간별 자동 정리

## 운영
- config.js는 업데이트 ZIP에서 제외
- 관리자만 Supabase URL/key 설정
- 기사에게 연결설정 메뉴 미노출
- Collector 백그라운드와 제어센터 분리
- 시작/종료/갱신 시 collector_config/state 미초기화
