# v1.0.1 로그인 crypt() 오류 수정

## 증상
Supabase RPC 로그인 시 다음과 비슷한 오류:
- `function crypt(text, text) does not exist`
- `function crypt(unknown, text) does not exist`

## 원인
Supabase의 `pgcrypto`가 보통 `extensions` 스키마에 설치되지만, v1.0.0 SECURITY DEFINER 함수의 search_path가 `public`으로만 고정되어 있어 `crypt()`/`gen_salt()`를 찾지 못함.

## 수정
- 신규 설치 SQL: `search_path=public,extensions`
- 기존 설치 DB: `sql/02_login_crypt_hotfix.sql` 1회 실행
- 데이터 삭제/재생성 불필요
