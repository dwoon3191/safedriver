# SafeDrive AI v1.4.0 시스템 구조

```text
[일일 배차표] ----┐
[노선 운행시간표] -┼--> 예정 기사·노선·회차·차량
                    │
[TAGO/BIS 실시간] --┘--> 실제차량 유효구간/차량변경(최소정보)
                                  │
[CDT 폴더 감시] ------------------┘
  실제 운행일 판독 -> 과거 배차/BIS 연결 -> 기사별 집계
                                  │
            [Supabase 최소저장 DB]
                                  │
    [Netlify 관리자/기사 반응형 웹앱]
```

## 저장 원칙
- Supabase: 배차, 시간표, 실제차량 연결, CDT 메타, 기사별 집계, 대표사건
- 회사 PC: CDT 원본, 1초 분석근거, Collector 설정·상태
- 저장하지 않음: 전체 BIS 위치 스트림, 전체 CDT 1초 레코드, API key/비밀번호

## 수집 진단
통합 제어센터가 Supabase 로그인, 명령 RPC, CDT 폴더, TAGO 도시코드, 노선정보, 버스위치정보를 순차 검사합니다.
