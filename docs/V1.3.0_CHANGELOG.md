# v1.3.0 변경사항

## 오류 수정
- PostgreSQL `collector_fetch_commands`의 데이터변경 CTE 중첩 오류 수정
- 원격명령 조회 실패가 CDT/BIS 수집 자체를 중단하지 않도록 분리
- 명령 RPC가 정상화되면 과거 명령조회 오류상태를 정리

## Collector 통합 제어센터
- 사용자 실행파일을 `SafeDrive_Collector_Control.bat`로 단일화
- 설정 화면, 키 마스킹, 연결진단, 자동실행 설치/제거, 수집 제어 통합
- 제어센터를 닫아도 백그라운드 수집 지속
- 상태·설정파일 무리셋 정책 유지
- 최근 BIS 비교에 노선별 예정차량/실제차량/누락/추가차량 표시

## 웹앱
- 관리자 최초 기기 Supabase 연결확인
- 기사 로그인에는 연결설정 미표시
- 배차·시간표·BIS·CDT 연계확인 화면 추가
- 기사 로그인 횟수·사용시간·온라인 상태 표시
- 2026-10-01 이후 일·월별 기사 분석

## DB
- 로그인 세션 활동이력 및 사용시간 집계
- 관리자 연계상태 조회 RPC
- 월별 위험운전 건수와 100km당 발생률 집계
