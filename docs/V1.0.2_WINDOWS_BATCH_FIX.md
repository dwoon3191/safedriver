# v1.0.2 Windows Collector batch fix

## Fixed
- Rebuilt setup_windows.bat as ASCII + CRLF + no BOM.
- Rebuilt start_collector.bat as ASCII + CRLF + no BOM.
- Rebuilt install_autostart_task.bat as ASCII + CRLF + no BOM.
- Added remove_autostart_task.bat.
- Added collector_config.example.json.
- v1.0.1 package accidentally omitted the BAT files; v1.0.2 includes them.

## Correct order
1. Install Python 3.10+ and select Add Python to PATH.
2. Run setup_windows.bat.
3. Edit and save collector_config.json.
4. Run start_collector.bat and verify collection.
5. Only after manual verification, right-click install_autostart_task.bat and Run as administrator.
